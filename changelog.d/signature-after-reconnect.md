### A mailbox added again after its removal can save its signature

Removing a mailbox that had a signature and adding the same address again left Settings → Signatures
showing the removed copy beside the new one, with the old sign-off on it, and every Save on that copy
failed with "try again". A removed mailbox now has no editor there and its old signature is no longer
offered to compose; the address you added again owns its signature, starting empty. Bring the old one
back with Import settings, or type it again.

Removing a mailbox with "erase" now deletes its signature too, as its receipt says, and the server
clears the signatures that mailboxes erased in earlier releases still held.

When a signature cannot be saved because nothing organizes the mailbox yet, the pane now says so and
points to Settings → Mailboxes, instead of asking you to try again. Desktop, web and your own server.
