### Hovering a link in a letter no longer moves the letter

The host a link goes to, shown when you hover or focus a link in a designed letter, now floats in a small label under the link. It used to be written into the line, so it widened the link, and in a newsletter whose links are a row of buttons the buttons beside the hovered one moved under the pointer. A link whose text names a different site still shows that site in brackets, as before. On the desktop app and the web app.
