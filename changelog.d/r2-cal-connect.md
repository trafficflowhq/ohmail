### A calendar can be connected, on a server that keeps one

The server's side of connecting a calendar in ohmail 2.0: iCloud with the Apple Account and an app password, any other CalDAV server by its address, and a subscription by its address. There is no screen for it yet. What a person types is sealed on the server before it is stored and is never shown again; of a subscription's address only the host is kept in the clear. Connecting asks nothing of the calendar's provider: the organizer tries the sign-in afterwards, and the connection then says how that went. A connection can be removed with everything it brought, asked to check its provider now (once a minute), and signed in again with a new password or address. A server never reads a calendar at an address on its own network unless whoever runs it allows that with `OHCAL_ALLOW_PRIVATE=1`, on the server and the organizer both; ohmail Cloud never does. Connecting is asked of the account's own server in a browser: the desktop app and the phone do not offer it yet. Google and Microsoft calendars stay off: `OHCAL_CONNECT_GOOGLE` and `OHCAL_CONNECT_MICROSOFT` are reserved for them, and any value other than `1` or `0` refuses the server's start.
