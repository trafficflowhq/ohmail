### Custom Local Endpoint joins the desktop model providers

The desktop app's AI settings under Settings → Desktop now include a Custom Local Endpoint option alongside Anthropic, OpenAI, OpenCode Go and Ollama. Choosing it lets you point ohmail at any OpenAI- or Anthropic-compatible local runtime (such as Bionic, LM Studio or vLLM) with a custom Base URL, Model Name and optional local API key, without remote cloud key validation.
