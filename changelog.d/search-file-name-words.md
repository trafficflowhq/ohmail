### Search finds a letter by any part of a file name beside your other words

A search of two or more words matched a file name only by its first part. For a letter from Ines with `harbour-ledger-7731.pdf` attached, `ines harbour` found it, but `ines ledger`, `ines pdf` and `scan 7731` answered "Nothing matched exactly", although `ledger` alone found it. Each part of a file name is now a word of its letter in the search index: the parts between dashes, dots and underscores, and words and numbers written together, as in `HarbourLedger2026`. Letters already in your mailbox gain them too: ohmail indexes again the letters that carry a file name, a batch at a time and newest first, between syncs on Cloud and your own server and while the desktop app is idle on power. On the desktop app, Cloud and your own server; on the phone a file name is still found by one of its parts searched alone.
